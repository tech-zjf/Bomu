## 当前执行顺序

1. 已完成当前可独立推进的代码修复、必要回归和文档整理。新问题先按真实用例和资源边界复现，不增加空模块或通用框架。
2. 当前规范 Debug 包源码摘要为 `2e9af56002d63b6a43855e86e47802e4afcf61e6d1fec301bd9e9bf7d8f47999`，版本 `0.0.1 (2)`，仅 `en.lproj`。相对 `414fdba9…`，产品增加了 Library 滚动区与播放控件的辅助功能测试标识，工程增加独立、显式运行的 `BomuHitchUITests` 测量目标；默认逻辑/原生测试入口不启动它。新收据的身份核验、Debug 构建、Xcode 静态分析、160 项 Python 和 208 项无宿主 XCTest（2 项 APFS 专项按默认入口跳过）通过。UI 测量目标仅编译，尚无可用 hitch 数据；本轮隔离窗口的媒体库导入成功后按用户要求退出，临时目录清理。此前 `414fdba9…` 收据的三尺寸有限抽查和其它历史播放证据仍按各自记录使用，不宣称新包完整可见验收。下一步用当前规范包在唯一窗口完成播放中滚动测量，并根据可用的帧时长与调用栈判断热点。
3. A04 当前工具链单窗口 30 样本已补跑通过；首轮意外换屏原因仍待查。A07 普通同屏缩放 100 轮及 120 秒持续播放已通过；随后补 A08 真实声画与受控睡醒。A07 的跨屏、全屏及完整键盘访问仍遵守单独授权约定。
4. 证据齐全后做 A10 决策并更新任务状态。公开 beta 前仍须恢复操作界面、发行版本迁移矩阵、签名、公证和完整打包验收。
