## 2. 按设计稿完成 UI 对照（A01/A02）

- [ ] 在 960×640、1280×800、1440×900 pt 三种窗口尺寸分别对照 `player_plan/开发定稿/UI设计稿.html` 和 `设计规范.json`。
- [ ] 逐屏检查 Home、Library、Folders、Favorites、Search、Settings 的内容边界、标题区、滚动区、空/加载/错误状态和卡片槽位。
- [ ] Search 检查：搜索框填满内容宽度，左右与标题/结果区对齐；搜索、无结果和结果状态不改变栏宽或纵向节奏。
- [ ] Player 检查：画布固定 16:9、外边距 12 pt；文件信息与画布分开，水平 24 pt、上/下 3/17 pt；竖屏与宽屏视频均在画布内保留比例并以较长边适配，不带动画布变形。

- [ ] 完成键盘焦点与 VoiceOver 浏览；覆盖网格/列表、菜单、文件面板和播放器控件。
- [ ] 对确认通过的尺寸和状态保留当前构建的截图及记录；已知系统标题栏/原生菜单差异按规格记录，不声称未经验证的像素一致。
