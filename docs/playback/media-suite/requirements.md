# A04 媒体矩阵与单窗口验证

日期：2026-10-13。基线为开发定稿 A04，以及用户对桌面测试的最新约束：允许实际占用桌面，只使用一个播放器窗口、留在同一块屏幕。

## 本轮范围

- 生成 30 个有来源、许可、SHA-256、实际媒体参数和明确预期的素材：28 个可播放文件、2 个故障文件。
- 对可播放素材先用 FFprobe 核对实际编码、位深、尺寸、帧率和音频格式，再完整解码所有音视频流；旋转、非方形像素、可变帧率要有真实元数据/时间戳依据。
- 使用正式 `PlayerScreen`、`PlayerModel` 和固定版本 libmpv，在同一个窗口与同一个播放会话内逐项验证加载、暂停、暂停中定位、恢复、故障后切换；记录失败，不因某项失败遗漏后续独立用例。
- 随后在该窗口执行 100 次暂停/恢复、一次最小化/恢复、120 秒持续播放、停止静默和顺序释放检查。
- 可见性分别按素材阶段、主动遮挡检查、持续播放阶段记录。主动最小化的中断不能污染持续播放结果，也不能被用来证明持续可见。

## 覆盖矩阵

| 维度 | 样本 |
| --- | --- |
| H.264 | Constrained Baseline、Main、High；480p、720p、1080p、4K |
| HEVC | Main 8-bit、Main10 SDR；1080p/4K；MP4/MKV |
| 画幅 | 16:9、9:16、1:1、21:9、720×576 非方形像素、90° 旋转 |
| 帧率 | 24、25、30、60、30000/1001、30/15 可变帧间隔 |
| 容器/音频 | MP4、MKV、MOV、MPEG-TS、WebM；AAC、FLAC、PCM、MP3、Opus |
| 轨道与边界 | 无音轨、纯音频、单/双声道、44.1/48/96 kHz、双音轨默认播放、中文和空格文件名 |
| 同步与错误 | 已核对源对齐的闪光/脉冲片、非法 MP4、仅剩 32 字节头部的 MP4 |

所有画面与声音由数学图案和波形生成，按 CC0-1.0 提供；没有个人录像、商业视频或第三方音画素材。生成器与测试代码纳入 Git，媒体、压缩包、构建和运行日志留在 `.build/`。完整 manifest 随素材包提供，精简且带校验值的验收证据在本目录归档。

## 完成边界

A04 的素材准备与播放器兼容性通过率是两件不同的事。30 个有许可的有效测试样本可完成素材准备；某个可播放样本测试失败时，整体播放验收仍失败，不能把它改成预期拒绝、删掉文件或降低断言后声称通过。

合成片覆盖参数组合，不代表所有相机/剪辑软件输出均兼容。本轮静音运行；音频解码参数和输出设备已建立不等于实际听感通过。源文件脉冲对齐、画面截图、帧提交统计都不能单独证明扬声器/屏幕的物理同步、色准或原生 HDR。双音轨样本只验证默认轨解码，不代表已交付音轨切换界面。

本轮实际结果见 [validation.md](validation.md)。v0.0 的其他验收缺口仍以 [原生播放需求](../native-poc/requirements.md) 为准。
