# 播放用运行库候选

更新：2026-10-14。状态：**开发依赖已固定接入通用 TS 定位修复；正式 Bomu 开发构建和单窗口回归通过。人工画面观感、听感与物理音画同步仍未确认，发行构建仍受 GPL/许可证流程限制。**候选阶段的历史过程和哈希保留在下文；当前锁、可重建流程与正式回归证据见 [TS 定位修复接入](ts-seek-integration.md)。

## 为什么需要新的构建配置

最初的 `diagnostic` 配置足以隔离 TS 定位故障，但关闭了 zlib、bzip2、iconv、Secure Transport、封装器以及部分解码配置。不能因为 TS 样本恢复播放就把它当成应用运行库。

实际补充检查确认了两个问题：

- 已有 CC0 MOV 的压缩头版本，在固定内核中能播放和定位，在精简候选中无法加载。该文件只压缩 `moov` 元数据，文件长度、媒体偏移与音视频负载保持不变；完整解码音视频校验值与原文件相同。
- 关闭解码器不仅影响单独生成的解码库。FFmpeg 的 `libavformat/demux.c` 也按 `CONFIG_H264_DECODER` 编译 H.264 解码器选择与帧重排判断；MOV 读取还依赖 H.261/H.263/MPEG-4 配置。两个丢失的导出符号因此提示了实际读取路径差异。

`playback-format` 配置恢复默认原生解码器配置、封装器、系统压缩/字符转换库和 TLS。macOS 显式链接系统 iconv，不依赖自动探测刚好选中本机库。其他外部功能仍由原版固定的 libmpv、libavcodec 等运行库承担；实验目录中只有 `libavformat.63.dylib` 被替换。

这是固定版本 FFmpeg 9.0.1 解封装组件的候选构建。它没有实现网络产品功能、播放转码或新的 Swift 状态模型。编码器配置和封装默认值不属于本轮读取行为验证，清单相同不能解释为任意输入或全部 FFmpeg 行为已等价。

## 构建与验证合同

入口和复现步骤见 [SeekProbe](../../../Tools/SeekProbe/README.md#播放用解封装配置与候选应用)。使用同一份官方源码、固定工具链和相同构建参数，分别生成未修改版本与 TS 修正版本。源文件、修正、运行库及媒体均记录 SHA-256；原版运行库仍是独立对照。

`runtime_capabilities.py` 每次只在一个进程加载一组库，避免动态加载器将同名库混用。清单按名称和出现次数比较，不只比较总数；包括版本、库许可和 arm64 导出符号。任何差异会在原生媒体回归前阻止播放配置通过。

## 实测结果

以下为 Xcode 26.1.1 下的历史运行，原目录为 `.build/seek-candidates/20261013-232523/`。候选应用、重复运行库和源码树已于 2026-10-16 因磁盘空间不足清理；带原始报告、源码和媒体哈希的归档证据见 [format-runtime-validation-2026-10-13.json](format-runtime-validation-2026-10-13.json)。需要复现时按 [SeekProbe](../../../Tools/SeekProbe/README.md) 重新生成。

- **9/9 候选内核用例通过**：短 TS、相同负载 MP4/MKV、长 TS/MP4、H.265 Main10 TS、MPEG-2 TS、纯音频 TS、压缩 MOV。定位后必须有新帧并能继续播放，不能只靠时间变化通过。原版和未修改重编仍复现 TS 故障，容器及压缩 MOV 对照通过。
- **交错回归通过**：短 TS、长 TS、MP4 各完成连续前后定位、100 条快速定位、定位请求后立即替换/停止；候选另做 10 次加载排队后立即关闭。原版 MP4 和关闭对照通过，原版 TS 的缺陷仍有有效帧记录证明。
- **独立重建字节一致**：在另一个目录重新解压、应用修正并构建，候选库 SHA-256 都是 `d376ff4eae9342a1acf32f79f0c498d40cda086874e34481cece94eb7426ed5f`。这验证当时 Xcode 26.1.1 与该配置下两次构建一致，不承诺任意机器或工具链输出一致。
- **52 项 Python 行为测试通过**；原生 probe 严格编译通过；`BomuBenchmark` 开发构建与候选应用的本地签名验证通过。

纯音频 TS 的本轮暂停位置为 2.805 秒，目标是 3 秒，约 195 毫秒的差异落在现有 0.2 秒断言内；不将该结果描述为帧级音频定位或实际听感验收。声音仍送入 null 输出，帧仍写入内存，本轮没有物理音画同步证据。
