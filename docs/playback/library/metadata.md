# 本地媒体属性探测

## 探测路径

媒体卡片或文件夹列表行显示时，`MediaLibraryModel.metadata(for:)` 把稳定媒体 ID、内容版本和本地 URL 交给 `MediaMetadataProbe`。探测器和缩略图生成共用应用级许可：平时合计最多两个工作，播放期间合计最多一个。见 [媒体工作预算](media-work-budget.md)。探测器使用 AVFoundation 读取容器时长、视频轨道像素尺寸/格式描述及逐条音频轨道格式。两种浏览密度共用同一元数据摘要；视频显示可用的真实时长、分辨率和视频编码，音频文件显示可用的真实时长和音轨信息。没有适合紧凑展示的已知属性时，属性行显示 `Unknown`，独立的大小行仍显示文件系统报告的实际字节数；文件大小不是媒体推断值。时长小于一小时采用 `m:ss`，长时采用 `h:mm:ss`，超出安全格式范围时不展示。列表行的媒体按钮将已知技术属性和真实文件大小作为辅助功能值提供，不重复朗读“未知”。音轨数组保留每条轨道的编码；汇总中只列已知编码，成功读到空数组才表示无音轨。同媒体 ID 与内容版本的并发请求合并，单个等待者取消不会打断其他等待者；最后一人取消则取消工作。取得许可后的探测以十秒为限，取消时调用父 AVAsset 的 `cancelLoading()`；失败、取消、超时与全未知结果不缓存。结果只缓存在当前进程，以媒体 ID + 内容版本区分并按最近使用顺序淘汰，最多保留 2,048 条，避免大库浏览让进程缓存持续增长；文件内容变化后不会复用旧结果。

缩略图仍由独立的 `MediaThumbnailCache` 生成真实画面。媒体详情继续展示原始文件名；未知分类和未知媒体技术属性不触发自动命名、编码推断或封面替换。

音轨编码在探测边界转换为界面标签；已知的 `flac` / `fLaC` 显示为 `FLAC`，与 AAC、PCM、MP3 的现有展示规则一致。转换只影响文字，不从扩展名推断编码。AVFoundation 无法确认的容器仍显示未知。

网格卡片和文件夹列表行的异步属性展示也绑定媒体 ID、相对路径及内容版本。SwiftUI 视图在版本切换时即使暂时保留上一轮的内部状态，也只向界面提供当前键的结果；新属性返回前显示明确的加载文案，不把旧编码、时长或尺寸误报为新文件事实。收藏、已看和播放进度变化不改变内容键，因此不触发无关的属性占位。

2026-10-23 将缩略图与属性加载任务的 SwiftUI `id` 改为包含媒体展示键、页面可见性及文件可播放状态的结构化值。旧实现以连字符拼接字段；结构化值按每个字段比较，路径或版本变化时不依赖字符串分隔规则来决定是否取消并重启任务。返回结果仍只按媒体展示键决定是否可见，在线状态变化会重新尝试加载。Debug 构建、Xcode 静态分析、148 项 Python 检查与 182 项无宿主 XCTest 通过（2 项专项存储用例按入口跳过）；这些检查没有模拟 SwiftUI 中真实文件替换的逐帧显示，后者仍待可见验收。

## 缺失与失败

无法读取的容器、不可用 URL、无效时长和不可识别格式字段保持为空。完整技术属性详情在所有字段都为空时显示一次“未知”；卡片和列表行的属性行显示 `Unknown`，大小行保留真实文件大小，辅助功能摘要只包含已知技术属性并保留文件大小。只有成功探测且确认音轨数为零时才显示“无音轨”。音频文件没有视频尺寸或视频编码时不展示这些不适用属性。探测错误不会影响播放文件，也不修改源文件。

首版使用 AVFoundation 对可访问的本地容器进行属性探测，不承诺覆盖所有 libmpv 可解码格式。AVFoundation 无法确认或当前进程没有目录访问权限时，字段继续显示未知；播放内核支持范围由实际播放和兼容样本验证。来源目录的可移植安全书签仍属 C03 后续工作。

## 验证

`MediaMetadataProbeTests` 使用项目脚本生成的 CC0 合成视频，验证 15 秒、960×540、H.264、一个 AAC 音轨，并用混合 AAC/ALAC 样本验证两条音轨分别保留各自编码；无效容器测试验证字段保持未知。缺失元数据的展示测试验证卡片/列表回退到真实文件大小、完整详情只显示一次未知，辅助功能摘要不会重复未知且保留文件大小。LRU 行为测试将容量设为 2，通过替换源文件内容验证近期访问项仍命中、淘汰项会重新探测。`test-dev.sh` 在测试前验证 fixture manifest，缺少新版合成样本时先校验旧素材再生成新版素材。屏幕 1 单窗口检查已确认 Debug 网格卡片和文件夹列表行在当前大窗口均显示实际文件大小，辅助功能树与可见值一致；列表使用 `corrupt.mp4`（41 bytes）和无可探测属性的 `mpeg2` 样本（713 kB）核对。VoiceOver 朗读和其他标准窗口尺寸仍待验收。

2026-10-24 的规范 Debug 包在隔离资料库加载许可套件后，Library List 的 `26-audio-flac.flac` 辅助功能值与窗口截图均显示 `FLAC`，PCM、AAC 及未知行布局保持正常；没有借此验证 FLAC 播放。收据和清理结果见[可见记录](../../engineering/roadmap/visible-acceptance-2026-10-24.md#最新包的-flac-标签可见复核)。
