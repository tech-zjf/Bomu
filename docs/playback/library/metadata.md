# 本地媒体属性探测

## 探测路径

媒体卡片或文件夹列表行显示时，`MediaLibraryModel.metadata(for:)` 把稳定媒体 ID、内容版本和本地 URL 交给 `MediaMetadataProbe`。探测器最多同时读取两个文件，使用 AVFoundation 读取容器时长、视频轨道像素尺寸/格式描述及逐条音频轨道格式。两种浏览密度共用同一元数据摘要；视频显示真实时长、分辨率、视频编码及音轨摘要，音频文件只显示时长和音轨摘要。时长小于一小时采用 `m:ss`，长时采用 `h:mm:ss`，超出安全格式范围时显示未知。列表行的媒体按钮将当前元数据作为辅助功能值提供，避免可见信息只对视觉用户可读。音轨数组保留每条轨道的编码；无法读取单条轨道编码时仅该条显示未知，成功读到空数组才表示无音轨。结果只缓存在当前进程，以媒体 ID + 内容版本区分并按最近使用顺序淘汰，最多保留 2,048 条，避免大库浏览让进程缓存持续增长；文件内容变化后不会复用旧结果。

缩略图仍由独立的 `MediaThumbnailCache` 生成真实画面。媒体详情继续展示原始文件名；未知分类和未知媒体技术属性不触发自动命名、编码推断或封面替换。

## 缺失与失败

无法读取的容器、不可用 URL、无效时长和不可识别格式字段保持为空。UI 对空值显示“未知”；只有成功探测且确认音轨数为零时才显示“无音轨”。音频文件没有视频尺寸或视频编码时对应值仍未知。探测错误不会影响播放文件，也不修改源文件。

首版使用 AVFoundation 对可访问的本地容器进行属性探测，不承诺覆盖所有 libmpv 可解码格式。AVFoundation 无法确认或当前进程没有目录访问权限时，字段继续显示未知；播放内核支持范围由实际播放和兼容样本验证。来源目录的可移植安全书签仍属 C03 后续工作。

## 验证

`MediaMetadataProbeTests` 使用项目脚本生成的 CC0 合成视频，验证 15 秒、960×540、H.264、一个 AAC 音轨，并用混合 AAC/ALAC 样本验证两条音轨分别保留各自编码；无效容器测试验证字段保持未知。LRU 行为测试将容量设为 2，通过替换源文件内容验证近期访问项仍命中、淘汰项会重新探测。`test-dev.sh` 在测试前验证 fixture manifest，缺少新版合成样本时先校验旧素材再生成新版素材。卡片/列表的实际排版和辅助功能朗读待屏幕 1 单窗口验收。
