# v0.0.1-dev.2 开发里程碑

本次是私有 GitHub 仓库的开发预览快照，不包含公开发行安装包，v0.0 阶段仍在验收中。历史 `v0.0.1-dev.1` 标记保留。

## 相对 dev.1 的变化

- 建立 30 个 CC0 合成媒体样本、生成与完整性校验、单窗口矩阵回归。
- 修复切换到纯音频时残留视频画面；按真实视频输出生命周期清屏。
- 将 TS 中途精确定位故障缩小到 FFmpeg 解封装层，加入固定源码构建、原版对照、能力清单、9 组媒体与交错退出验证。候选仍与正式依赖隔离。
- 补齐 MKV 系统文件类型声明；所有打开按钮与 ⌘O 共用附着选择面板，重复触发不会叠加。

## 验证与限制

本轮正式构建、52 项 Python 与 12 项 Swift 逻辑测试通过。三种 MKV、MP4 对照、面板重复打开与取消在同一播放器窗口实际验证，见 [文件打开记录](file-opening.md)。

dev.1 之后的正式运行库矩阵为 **29/30**：TS 定位仍未通过。同窗口 100 次暂停恢复、120 秒连续出帧、停止后无新增绘制和退出释放的证据见 [媒体矩阵验证](../media-suite/validation.md)。这一历史运行使用相同播放/渲染代码；不能将本轮入口验证写成重跑了完整矩阵。

TS 候选的 9 组内核回归、能力清单、交错操作及重复构建一致性已通过；截至本标记归档时，可见验收仍待完成，正式缓存未替换。后续进展见 [运行库候选](../media-suite/runtime-candidate.md)。
