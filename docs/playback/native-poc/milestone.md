# v0.0.1-dev.1 开发里程碑

日期：2026-10-13（Asia/Shanghai）。

这是可回溯的开发快照，覆盖 v0.0 的最小原生播放链路及两轮审查修复。Git 标记为 `v0.0.1-dev.1`，应用版本仍为 `0.0.1`、构建号 `1`。该标记不表示 v0.0 阶段验收完成，也不包含可公开分发的安装包。

## 本次范围

- 固定 macOS 14+ / arm64、Swift 6、Xcode / SDK 与 libmpv / FFmpeg 开发依赖；有依赖校验和可重复构建入口。
- 原生单文件打开、真实画面和声音、暂停/恢复、前后跳转、时间线、音量、原生全屏、自然结束、停止及错误后恢复。
- 按 `App`、`PlayerFeature`、`Playback`、`Rendering`、`DesignSystem` 分离职责；稳定持有播放会话，按顺序释放渲染资源和内核。
- 修复暂停交错确认、连续定位累计、提交时序与 CPU 测量口径；测试工具增加素材完整性校验、Python 3.9 兼容和窗口遮挡事件记录。
- 保留调用链、原始测量摘要、失败记录、源码与日志校验值。测试视频、运行库缓存及构建产物留在本机 `.build/`，不纳入提交。

## 验证依据

最新验证通过 17 项 Python 行为测试、12 项无界面 Swift 逻辑测试及 4 项选定的真实内核回归，共 33 项。正式应用与独立基准工具构建通过。版本归档前核对了该轮记录中的 50 个源码文件、6 个日志的 SHA-256，均与本机文件一致，并重新检查了依赖完整性。

本次归档没有重新运行可见测试。原生回归用例的选择、通过结果与限制见 [验证记录](review-fixes-validation-2026-10-13.json)；各轮测量与审查修复见 [审查跟进](review-follow-up.md)。

## 下一步

1. **先补 A04 测试素材矩阵。** 建立 30 个有明确来源/许可的代表样本及 manifest，覆盖已规划的 H.264、H.265 Main10、同步片和失败场景；用后台回归验证，不以同片复制数量代替覆盖。
2. **收尾 v0.0 验收。** 在同一个普通窗口验证新的遮挡记录与持续播放；补真实音画同步、SDR 颜色、首声/GPU 与长期资源证据。完整全屏/跨屏组合测试继续保留为未通过项，只有用户针对桌面操作明确允许时才安排。
3. **完成 A10 决策后进入 v0.1。** 基于当前播放契约，依次完善多文件/目录打开与拖放、字幕/音轨/倍速、播放队列和断点续播。更后的媒体库、网络服务与发行能力保持原版本范围。

完整验收缺口以 [requirements.md](requirements.md#尚未完成的-v00-验收) 为准，产品任务依赖仍以 `player_plan/开发定稿/开发任务.json` 为准；本里程碑不修改规划的完成状态。
