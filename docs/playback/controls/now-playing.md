# 系统媒体键与 Now Playing

`NowPlayingController` 只在 `PlaybackState.phase == .ready` 时向系统共享命令中心注册播放、暂停、切换、上一项和下一项处理器。切换到新媒体、停止、结束、失败、窗口关闭或应用退出时，它移除自己的 handler、禁用对应命令并清空 Now Playing 信息。没有播放会话时不持有系统媒体命令。

命令处理通过 `PlayerModel` 提交已有播放意图；队列边界会同步反映在上一项/下一项命令的启用状态。Now Playing 只公开媒体文件名、时长、播放位置和播放速率，不发布原始路径。位置每秒最多刷新一次，暂停、速度、曲目或时长变化时立即刷新。

## 验证

- Debug 构建通过，编译采用 Xcode 27.0 与 Swift 6 严格并发检查。
- 代码路径没有安装应用级全局键盘事件监听器。
- 锁屏期间不能操作系统媒体键或屏幕控件；实际控制中心显示、硬件媒体键响应和切换应用后的命令归属仍待可见验收。
