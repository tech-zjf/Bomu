# 播放键盘事件归属

## 最终合同与调用链

`MainWindowView` 将播放器是否可见传给 `PlayerScreen`。播放器根视图通过 SwiftUI `focusable(interactions: .edit)`、`FocusState` 与 `onKeyPress` 接收响应链内的按键；不安装全局或本地事件监听器。键盘事件 → 页面检查 AppKit 文本编辑/系统面板与焦点归属 → 纯值策略 `PlaybackKeyboardAction.resolve` → 关闭浮层、退出全屏、返回浏览或提交 `PlayerModel` 意图。

Esc 的优先级是媒体信息、错误详情、命令错误提示、全屏、返回上个浏览页面。重复按下 Esc 不跨越多个层级。空格在播放器根焦点切换暂停，左右键按 10 秒定位；重复空格不连续切换，左右键允许连续定位。带 Command/Control/Option/Shift 的键由其他响应者处理。

输入框、输入法组合文本、系统文件面板、隐藏播放器均不接管这些按键；按钮、滑块、菜单拥有焦点时保留自己的空格与方向键行为。点击播放画面背景可重新取得播放器根焦点。原菜单中的裸空格/左右键快捷键已移除，菜单操作本身保留，避免菜单优先截获文本编辑。
