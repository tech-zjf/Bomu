The current typography direction reserves the system serif design (New York on Apple platforms) for the brand. Welcome and other page titles use the reference's SF/system sans style; the Welcome title uses 38 pt bold with −1.6 pt tracking. Navigation, section headings, descriptions, controls, filenames, and media metadata also stay sans-serif. Time values use monospaced digits. Common headline, callout, and caption roles resolve to explicit point sizes instead of environment-dependent semantic font sizes. Secondary text uses the shared `#647084` token where the reference calls for it. No external fonts are bundled.

This role split gives the brand a distinct display face while keeping page copy and repeated library labels in a consistent sans-serif family. The 2026-10-26 serif Welcome experiment is retained in its historical acceptance notes below; the current `AGENTS.md` restricts serif to the brand, so the Welcome title has returned to the reference's sans-serif family. Bomu uses SwiftUI system fonts and does not ship a font file. The recent IINA 1.5 redesign was consulted for native media-app spacing and inspector consistency, without copying its typography or layout.
