# Security policy

Bomu is pre-release software. There are no published supported-release versions or response-time commitments yet; reports about the current development branch are welcome.

Please report suspected vulnerabilities privately through GitHub's **Report a vulnerability** action on this repository. If private reporting is unavailable, contact the repository maintainer through their GitHub profile. Do not publish exploit details or affected users' data in a public issue before coordinating disclosure.

Include the affected commit or build, macOS version, reproduction steps, and a concise impact description. Remove personal paths, media, credentials, and other private data from logs or attachments.
